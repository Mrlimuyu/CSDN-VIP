# CSDN-VIP

100%解锁CSDN文库VIP文章阅读限制 · 去除VIP文章遮罩

## 安装使用

1. 安装浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey（暴力猴）](https://violentmonkey.github.io/)
2. 点击扩展图标 → 添加新脚本 → 粘贴本仓库 `.user.js` 文件内容 → 保存
3. 打开任意 CSDN 文章页面，脚本自动生效

## 支持站点

- `blog.csdn.net` — 博客文章
- `wenku.csdn.net` — 文库文档
- `download.csdn.net` — 下载页
- `*.blog.csdn.net` — 个人博客子域名

## 功能一览

| 功能 | 说明 |
|------|------|
| 阅读全文 | 移除"关注博主/登录后查看全文"遮罩，展开被截断的文章内容 |
| VIP文章解锁 | 移除 VIP 文章遮罩层 |
| 免登录复制 | 解除复制/选择限制，事件拦截 |
| 代码块展开 | 自动展开折叠的代码块，移除"展开全部"按钮 |
| 登录弹窗移除 | 自动关闭登录提示弹窗，恢复页面滚动 |
